## 基线与执行规则

`main@9858f1ce4be21c23741f747bc445468413a6951a`。工作区原有三项未跟踪

完整功能树有 1982 个层级节点、1625 个末级条目；其中包含字段、交互、安全约束与验收要求，
不是1625个彼此独立的功能，也不是全部重写的任务。有代码的内容先保留与补验，缺口才新增实现。
执行状态以 [execution-tracker.json](execution-tracker.json) 为准；没有证据的条目不记“完成”。

- 保留 Go + Vue/TypeScript + MySQL、原生 Linux。当前主控/被控支持目标为 Ubuntu22.04/24.04 amd64，26暂不支持。
- 财务 Ubuntu22/24完整原生链已在128a86d独立通过；新源码仍须自身门禁。Cloud的软件准备和doctor不能替财务或目标主机背书。
- 中文/CNY默认，语言与币种独立；类型→地区→节点→套餐，单选仍有框，默认首个已发布套餐。
- 不改现有金额计算、支付幂等、安全协议、历史订单/账单/币种快照。新资金能力须先单独设计版本化规则，不能顺手接入旧资金路径。
- 主控、财务、被控各有状态权威；付款、任务受理和VM就绪不是同一状态。管理员拥有全部定义的业务权限，不获得越过状态机的任意权限。
- 只更新main；不覆盖旧标签和资产，不重新改写历史。版本候选、代码实现、正式发行与生产验收分别记账。
- 真KVM/物理网络验收按既定决定后置；先继续代码、隔离执行器、真实MySQL和浏览器工作，不把替身算成真机。
- 每个工作包遵循：现状/接口与状态设计 → 回归负例 → 实现 → 定向测试 → 完整相关测试 → 证据与文档 → 下一个包。
- 与UI相关的交付必须检查真实页面；单元测试绿不等于视觉完成。现有设计语言不推倒重写，不给外部模型源码、旧UI图或凭据。

### W05的局部设计

- 状态所有者仍为 `useMutation`，页面只消费忙碌、错误和原操作ID，不新增全局业务store。
- 不按前64条截取持久化记录；完整校验后一次提交内存，格式异常/重复冲突/超预算保留原存储并拒绝写操作。
- 存储预算限制的是同时未核实的意图数据量，不是累计操作次数；已核实结果只清除匹配账号/完整原操作的记录。
- 保存成功必须早于HTTP写请求；存储失败、丢ACK、重挂载/刷新和身份改变均不能另造成功或重发。
- 使用既有公开测试边界及其回归fixture；测试内明确区分模拟HTTP、浏览器sessionStorage与真实后端验收。

## 后续工作包：每项都必须做成前后端闭环

### W07 身份、管理员与客户权限

1. 财务保留现有admin/customer与最后管理员保护，再增加可配置权限组、只读财务/客服等数据域。
2. 主控补用户列表完整分页；后端权限、对象归属、状态许可与前端入口一致，深链不能绕过。
3. 管理员MFA、恢复码、会话撤销、敏感动作重新认证；客户SSO使用短期一次性票据，不能直接沿用管理员身份。
4. SMTP业务通知、验证/找回、安全限流与审计分别定合同；密码、Cookie、票据和密钥不入日志。
5. 验收：双角色/双租户、权限变更后的旧会话、最后管理员并发修改、失效票据/重放、账号恢复负例。

### W08 财务→主控→服务交付

1. 基于既有不可变产品配置和paid订单任务设计专用worker，不给Web进程shell、主机密钥或财务DDL。
2. 原子领取、并发同节点门禁、发送前持久化、崩溃/丢ACK只读对账；不自动重派未知结果。
3. 后台任务中心：分页/筛选/原请求与快照/执行阶段/错误/核对入口/审计；不是只保留root one-shot CLI。
4. 经主控核验实例身份/owner/请求摘要后回填财务服务投影；迁移、公网IP与电源状态变化可核对。
5. 客户只能查看/操作本人的服务；就绪与失败分别显示，实例动作不改变账单已付状态。
6. 验收：真实MySQL事务、重复事件、并发worker、发送后崩溃、跨租户、无回执恢复，以及真实API浏览器闭环。真VM效果另验。

### W09 节点、目录、镜像与批准配置

1. 区域/集群/节点组、规格、镜像与预设可管理，启停和排序不破坏已引用资源。
2. 一命令安装后，节点待审批→证书/能力验证→维护→可调度；心跳过期、版本不兼容与资源不足不能调度。
3. root批准的路径、网络、镜像、配额投影给后台；后台只能发结构化意图，不接受任意命令/设备路径。
4. 容量预留、并发耗尽、维护排空与配置版本化；引用仍存在时禁止危险删除。
5. 验收：证书错pin/过期、镜像摘要、资源并发、重启与离线恢复；不能用在线标志替代迁移兼容。

### W10 实例与客户日常操作

1. 实例创建、电源、锁定、业务暂停/恢复、回收站分别定义状态和任务，不用删除冒充重装。
2. 受控VNC/串口：短期票据、实例归属、目标白名单、过期/撤销/审计，无开放宿主VNC端口。
3. 重装、救援、ISO、guest agent与密码重置；初始化秘密按生命周期销毁，不回显进日志。
4. CPU/内存变配、系统盘扩容、独立数据盘、挂卸载、I/O限额；明确热/冷操作与回退边界。
5. 验收：旧协议明确拒绝未支持动作；失败不双启动、不丢磁盘/网络归属；前后端任务进度一致。

### W11 OVS感知存储、备份与迁移

1. 新存储/迁移合同绑定VPC、MAC/IP、浮动/直绑资源和网络版本；不能直接删除现有OVS拒绝保护。
2. 停止态快照、恢复和系统盘备份完整闭环；存储预算、目录属主/符号链接、摘要和持久状态校验。
3. 定时备份、保留期、失败告警、异地副本、剪枝和隔离恢复；不是“备份文件存在”即成功。
4. 冷迁移准备/传输/导入/激活/源退役完整阶段；fence与资源占位直到有明确证据才释放。
5. 验收：双节点流式中断、丢ACK、重复阶段、磁盘满、代数冲突、源清理失败与重启恢复；真数据面后置但必须记账。

### W12 VPC、IP与公网安全

1. 保留已有OVS真正接入VM生命周期、跨节点VPC、路由、NAT和恢复链；继续补状态可见性，不重建独立CLI演示。
2. 公网池补充/启停/分配/回收、NAT出口绑定、直绑与浮动地址迁移；并发末地址不双分，未知任务不放回池。
3. 路由下一跳/批准前缀、SNAT/DNAT端口映射、恢复版本依据可在后台管理；默认不开放未经批准的公网流量。
4. 完整安全组覆盖入站/出站/东西向/直绑；IPv6、多IPv4、DHCP在新合同完成前明确不支持，不能仅显示字段。
5. 限速、流量周期、历史计量和额度策略独立于财务金额引擎；实时计数不等于可计费账本。
6. 验收：双租户、跨节点、伪造ARP/MAC/IP、出口保护、规则原子性、重启与恢复；真实吞吐/物理上联另验。

### W13 生产安全、日志与灾备

1. 非root控制面与最小受限宿主执行面分离；证书、凭据轮换/吊销、密钥恢复和权限审计。
2. 订单→开通job→主控任务→被控→网络版本的关联检索；业务审计、运行诊断、恢复journal分开。
3. 可配置保留/容量/外送、审计归档与导出权限；诊断日志丢行不得清理幂等/未知任务/fence。
4. 心跳、容量、任务积压、backup-age、TLS到期、错误率、磁盘/inode与日志丢失告警；去重、恢复、抑制可审计。
5. 数据库、磁盘、IP占位与journal一致性备份；异机恢复、RPO/RTO、维护停写和显式恢复流量。
6. 验收：秘密/日志注入负例、满盘、权限收敛、证书轮换、断电恢复；不能以JSON日志格式代替运维完成。
