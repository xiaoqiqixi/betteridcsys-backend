# 星屿云财务后端

商品、客户、订单与账单、插件和运营管理。完整介绍见[项目首页](../README.md)，操作指南见[使用文档](../docs/README.md)。

## 目录

- `backend/`：Go 服务、MySQL 迁移与测试。
- `deploy/`：原生安装、systemd/Nginx、升级和备份工具。
- `docs/`：安装、运营、接口与插件手册。
- `tests/`：跨组件回归工具。
