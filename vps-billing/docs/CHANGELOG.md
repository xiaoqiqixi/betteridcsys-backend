## 0.3.0 候选历史：品牌、双语、双币种与原生部署

准确版本、源码提交与构建工具链以 Release 的 `BUILD.json` 为准；实际测试见 [验证记录](VALIDATION.md)。

### 功能

- 管理员站点设置：品牌、支持方式、展示地址、预设标志/主题、账单身份和默认语言/币种；支持预览、权限/CSRF 校验、revision 冲突与事务审计。
- 简体中文/English 与 CNY/USD 独立选择，默认中文/CNY。`plan_prices` 为独立报价，不进行自动汇率换算；缺价或禁用币种不可购买。
- 订单和账单保存金额、币种及 issuer 快照；后续设置/价格变动不重写历史。财务汇总按币种计算，不受 1,000 条列表上限影响。
- 迁移 1–6 包含双币种、身份快照、金额精度、精确大写币种约束和 SMTP 设置表；校验完整历史与 checksum，处理已知中断状态。
- 官方 SMTP 默认关闭，管理员可保存带 revision 的配置和发送固定测试邮件；用户名/密码使用独立本机密钥加密，只写不回显。强制 TLS，限制发送频率，对不确定结果不自动重发。
- 选购页按 API 中的实际地区筛选套餐，集中展示规格、可售状态和所选币种的独立报价；桌面右侧订单摘要与手机布局同步更新，仍须确认后才创建待付款订单。

### 安全与正确性

- 修复 MySQL TLS 明文回退、IPv6 文本别名限速绕过和 JSON 媒体类型校验问题。
- 修复管理员账单详情路径、迟到账单响应、最大整数金额显示和不确定订单重试；同键修改币种或请求内容返回冲突。
- 套餐刷新后重新核验未提交的确认内容；价格、币种或可售状态变化时要求再次确认，已有不确定订单继续使用原请求和幂等键。磁盘展示不再假定 API 未提供的存储类型。
- 币种刷新期间保留选购组件，防止加载占位卸载组件而丢失已选地区和套餐；加载时隐藏旧报价并阻止确认，新增应用级延迟响应回归。
- 修复备份夹具测试在 `rg` 缺失时仍报告泄露扫描通过的问题；改用显式检查的 `grep`，区分匹配、无匹配及执行/读取错误，并覆盖工具缺失、退出码 2/127 和实际泄露标记。
- Go 测试跳过检测同样区分扫描错误与无匹配，工具或读取失败时停止后续验收。
- 更新测试依赖和 edwards25519；Go/npm 实际扫描范围单独记录，不以单项绿灯宣称所有依赖无漏洞。

### 部署与交付

- 单服务器 Linux amd64 原生部署：systemd API、Nginx HTTPS/静态网页、本机 MySQL 8.4 LTS；API 运行身份仅本库 DML。
- 原生备份采用私密配置、Unix socket、InnoDB 范围检查、新目录原子发布及可搬移校验和；提供隔离恢复流程。
- 精确提交快照打包、双构建比对、源码/工具链/依赖清单与许可证材料；只读 CI 与受信草稿发布分离。
- 补充 Ubuntu 24.04 安装、升级、回滚、备份恢复与 [宝塔部署指南](BAOTA.md)。

### 升级注意

没有向下迁移，旧二进制可能拒绝新版 schema。升级前备份并验证恢复副本；不能把目录切换当作数据库回滚。新增 CNY 示例价格默认不可售，既有 USD 可售状态可继承；实际产品和各币种价格必须分别审核。当前没有后台定价编辑器，使用 [受控 SQL 流程](SITE_SETTINGS.md)。

### 功能边界

支付保持禁用；SMTP 需显式准备密钥并由管理员启用，仅提供测试邮件。真实收款/退款/结算/对账、财务账本、邮箱验证/找回、MFA、完整账号生命周期、VPS 控制器、自动 DNS/TLS、税票/汇率/钱包和完整分页导出尚未实现。候选版本及 `production` 模式均不代表生产认证。
