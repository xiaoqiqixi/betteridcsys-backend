# 商品配置与开通边界

Core 0.6 的商品直接绑定 `{module_id, connection_id, config}`，不绑定模块时为人工开通。一个接口对应一台主控，节点与容量选择由主控完成。销售目录的地区和节点不参与资源放置。

配置由模块 `product_schema` 验证，保存规范化配置与 digest；订单和服务冻结购买时的配置。商品修改不改写历史快照，订单付款后才创建服务任务。商品配置、下单字段不得携带连接凭据；密码只允许直接动作的单次内存调用，或已有结账路径支持的单向 hash。

完整协议、安装、人工开通、镜像同步、主机命令和迁移见[服务器模块指南](SERVER_MODULES.md)。旧产品配置端点仍接受严格的模块无关 spec：`{mode:"module",module_id,connection_id,config}`；未启用时为 `mode:"disabled"`、两个 ID 为空、config 为 null。0.5.10 的主控 preset 配置须先通过插件迁移工具转换，不能直接交给新核心。

参考魔方财务与 WHMCS 的模块边界：销售、账务和生命周期属于财务；连接、资源开通与平台操作属于模块。协议是本系统自己的版本化接口，不声称兼容第三方原生 API。旧配置格式的记录保存在插件的历史文档中。
