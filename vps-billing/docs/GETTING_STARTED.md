# 财务系统首次使用

[财务首页](../README.md) · [安装手册](INSTALL.md) · [日常运维](OPERATIONS.md)

本文按“登录 → 设置站点 → 发布商品 → 客户购买 → 日常管理”说明当前界面。示例网址是占位值，应换成自己的站点；不要在生产站点为了验收创建真实收款或资源任务。

## 1. 登录自己的站点

**前提**：已按安装手册完成同版本网页/API、schema、服务与 HTTPS 检查，持有安装时设置的管理员账户。

1. 打开自己的 HTTPS 站点，例如 `https://billing.example.com/#/home`。
2. 点击“登录”，输入安装规格的 `bootstrap_email`，以及 `bootstrap_password_file` 中由自己设置的密码。
3. 登录后应出现“商品管理”“全站订单”“系统设置”等管理员入口。没有固定 `/admin` 登录页，也没有通用默认管理员密码。

**没有成功时**：先确认访问的是自己的正式站点，而非本地 demo；核对安装回执、HTTPS 与账户。429 限流按提示等待，不反复提交。已安装实例不要重跑 bootstrap 或删除账户表来解决登录问题，按[日志与审计](LOGGING.md)排查。

财务管理员与云主控管理员是独立账户；主控的 operator/viewer/custom 角色不能直接用于财务。

## 2. 设置品牌、语言与币种

入口：**系统设置**（`#/admin/settings`）。

1. 在“站点与品牌”核对站点名称、公司名称、支持方式及账单抬头；查看预览后保存。
2. 核对默认中文与 CNY；“运营币种”管理已启用币种，个人语言/购买币种选择不会改写全站设置。
3. 保持邮件、支付及资源扩展关闭，直到各自完成安装、授权和实际验收；保存一个配置不代表上游服务已可用。

**成功结果**：重新读取后仍为刚才保存的设置；历史账单的抬头、金额与币种格式保持原样。版本冲突时重新读取并核对，不拿旧表单覆盖别人的修改。

名称和展示地址不修改 DNS、TLS 或登录来源。已有价格/业务记录的币种精度已锁定，不能通过改默认币种或切换语言换算金额。详见[站点设置](SITE_SETTINGS.md)与[财务模型](FINANCIAL_MODEL.md)。

## 3. 发布第一个商品

入口：**商品管理**（`#/admin/catalog`）。

### 建立销售分类

1. 打开“类型、地区与节点”，建立需要的类型、所属地区与节点，设置排序并启用。
2. 填写操作原因后保存。即使只有一个地区或节点，也按完整分类维护。
3. 节点只是客户购买目录的分类。实际计算节点、镜像和存储在主控独立审批，不从同名销售分类推断。

分类引用、改名与停用规则见[商品分类](CATALOG_TAXONOMY.md)。已有在售引用时，先按规则下架商品再停用分类，不能删除历史订单。

### 填规格和独立价格

1. 选择“新增商品”，填写名称、分类和 CPU / 内存 / 磁盘 / 流量等销售规格。
2. 按币种单独填写价格并启用报价，例如审核 CNY 金额；不把 USD 数值当作 CNY 价格，不自动换汇。
3. 初次可先保存草稿，重新打开核对。复制商品会生成新 ID 并保持草稿，复制后也要重新审核报价。
4. 确认分类、商品与对应币种报价均可用，选择上架并填写原因保存。仅启用商品、但未提供所选币种有效报价，客户仍不能购买。

**成功结果**：客户“云服务器”目录 `#/catalog` 出现该商品；按后台分类顺序展示，默认选中当前节点的第一个已上架套餐，摘要显示它的实际报价。当前首项缺价时应显示不可购买，不自动跳到另一个套餐或使用别的币种补价。

如果销售商品将来要开通资源，再单独维护[产品配置](PRODUCT_CONFIGURATION.md)；无需开通时保持 disabled。商品上架不批准节点权限，也不会启动虚拟机。

## 4. 客户购买与账单

建议在隔离测试站点，由管理员创建合成客户后用独立浏览器会话验收；不要用管理员账户替客户付款。

1. 客户登录并打开“云服务器”（`#/catalog`），依次选择类型、地区、节点与套餐。
2. 核对规格、购买币种、金额和服务器名称，再进入购买确认；默认选择套餐不会自动下单。
3. 明确提交后，在“订单”查看新订单与关联账单。应为待付款，而不是已付或已开通。
4. 在“账单”查看详情。只有已配置并验证的支付渠道才可提供付款入口；默认关闭时应显示暂不可付款。
5. 从渠道返回后刷新账单，由后端确认付款状态；跳转成功页、支付链接或浏览器提示都不能代替入账证据。

**报价变化**：重新读取报价，由客户明确确认后再提交。**提交结果不确定**：先核对订单记录和原操作状态，不换 ID、改参数或连点按钮制造第二笔订单。幂等重放规则与价格变化是不同情况，详见[API 契约](CONTRACT.md)。

符合条件的未付订单可取消并联动作废账单；已付、存在在途支付或关联不安全时不能取消。当前没有人工把状态改成已付、退款或撤销资源的通用按钮。客户“我的服务器”读取已有服务，不因订单提交就新增一台实际 VM。

## 5. 日常管理入口

| 页面 | 用来做什么 | 不代表什么 |
| --- | --- | --- |
| 客户与角色 | 新建账户、改名/角色/启停、重置密码、撤销会话 | 目前只有客户与管理员，没有财务自定义员工权限组 |
| 全站订单 / 全站账单 | 看原始记录、订单详情、关联账单与符合条件的取消 | 不能任意改状态，不能代客户结账 |
| 全站服务 | 查看归属、规格、状态与历史金额 | 不是主控的开关机、重装或迁移面板 |
| 财务核对 | 按原币种读取已入账与待付数据 | 不是换汇汇总或完整会计/渠道对账系统 |
| 审计日志 | 按动作、操作者、所属账户与 UTC 时间查询业务事件 | 不是主机日志、HTTP 状态码或不可篡改账本 |
| 系统设置 → 版本与更新 | 核对官方版本、创建交接、读取脱敏主机回执 | 网页不会取得 root 权限或直接升级服务 |

敏感账户操作需要原因和当前版本；改密、角色/启停变化或撤会话后，目标旧会话会失效。最后一个启用管理员和自身降权/停用受后端保护。订单、账单和服务的既有限量列表不是全库搜索/导出，详见[管理员能力](ADMIN_MANAGEMENT.md)。

## 6. 常见情况与下一步

| 现象 | 先做什么 |
| --- | --- |
| 商品未出现 | 核对分类及商品是否启用/上架、分类归属与保存结果 |
| 能看到商品但不能购买 | 核对当前币种是否启用、是否存在有效且启用的独立报价 |
| 保存提示版本冲突 | 重新读取当前数据后核对差异，不自动重试覆盖 |
| 请求超时，结果未知 | 保留原操作记录，先只读核对；不以网络错误认定“没执行” |
| 已付款但没有服务器 | 分别核对财务结算和资源任务；当前没有自动开通 worker，不伪造服务成功 |
| 无法加载数据或会话失效 | 按提示重新登录/读取，并检查服务状态与日志；不切换演示数据冒充成功 |

开始运营前，按[验收清单](ACCEPTANCE.md)检查权限、账务约束、备份恢复和目标环境。支付与资源渠道、公共 CA 续期、容量及灾备另行验收。继续阅读：[插件管理](PLUGINS.md) · [支付接入](PAYMENT_PLUGINS.md) · [资源插件](RESOURCE_PLUGINS.md) · [升级回退](UPGRADE.md)。
